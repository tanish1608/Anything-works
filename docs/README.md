# Documentation guide

## Share the idea

Start with the [main README](../README.md), then the [pitch](PITCH.md). The product is AI checking daily construction updates for mistakes and incomplete work, with supported completion and findings reflected in 3D.

For teammates, continue with the [product specification](PRODUCT_SPEC.md), [build plan](../PLAN.md) and [task backlog](../TODO.md).

## Research

- [Construction pain research — October 5, 2026](CONSTRUCTION_PAIN_RESEARCH_2026-10-05.md)
- [US competitor research — October 5, 2026](COMPETITOR_RESEARCH_2026-10-05.md)

These dated research reports preserve the investigation at the time. Their earlier positioning and proposed wedges are not the current product specification. Capability claims, funding, prices and company information can change; verify before reusing them externally.

The pitch includes linked rework references and explicitly illustrative economics. Do not convert its historical 5% scenario into a claimed current average for US homebuilding.

## Document roles

README explains the idea; PRODUCT_SPEC defines intended behavior; PLAN defines the delivery approach; TODO tracks future work; STATUS records implemented reality. When they conflict, resolve the discrepancy explicitly rather than treating a planned feature as shipped.
